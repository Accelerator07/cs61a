VS Code + Python：跑起来、停下来

Windows 键位。打印出来放在手边，比翻课程快。

1. 每天都会按的键

按键作用什么时候用
Ctrl+`开关集成终端跑脚本、装包、看报错
Ctrl+Shift+`新开一个终端要同时跑两个东西
F5调试运行要断点、要看变量
Ctrl+F5不调试直接跑只想看输出
Shift+F5停止调试卡在死循环里
F9切换断点在当前行下／取消红点
F10单步跳过不进函数，往下走一行
F11单步进入钻进函数体
Shift+F11单步跳出这一层看够了
Ctrl+Shift+Y调试控制台现场敲表达式、调函数
Ctrl+Shift+P命令面板一切找不到的功能都从这里进

2. 终端里最常用的几条

python main.py                      # 跑脚本
python -m pdb main.py               # 命令行调试
python -m pip install 包名           # 装包（务必先确认提示符带 (.venv)）
python -m pip list                  # 看装了什么
python -c "import sys; print(sys.executable)"   # 我现在用的是哪个 Python
where python                        # 同上，看 PATH 里所有 python

# 虚拟环境（本项目已建好，换项目时才需要）
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # PowerShell 激活
.\.venv\Scripts\python.exe          # 不激活也能直接用它跑
deactivate                          # 退出环境
Windows 上没有 python3

敲 python3 会跳出去 Microsoft Store 的提示——那个 python3.exe 是商店占位符，不是 Python。在 Windows 上只认 python 和 py。

3. launch.json 里真正重要的字段

字段取值含义
typedebugpy新版调试器（旧配置写 python 也还能用）
requestlaunch / attach自己启动程序 / 连上已经在跑的程序
program${file}调试当前打开的文件
modulemain按模块跑，等价 python -m main
consoleintegratedTerminal输入输出走集成终端（推荐，input() 可用）
internalConsole走调试控制台，不支持 input()
externalTerminal弹独立窗口，适合要看满屏输出
cwd${workspaceFolder}工作目录，决定相对路径从哪算
args["--n", "8"]命令行参数
env{"PYTHONUTF8": "1"}给这次运行加环境变量
justMyCodefalse允许单步进第三方库内部；true 只看自己的代码
stopOnEntrytrue启动就停在第一行

4. pdb 命令（纯终端调试）

进去：python -m pdb main.py。提示符是 (Pdb)，直接敲命令回车。

命令作用
l / ll看当前位置前后代码 / 整个函数
n下一行，不进函数（next）
s进入函数（step）
r跑完当前函数并返回（return）
c继续到下一个断点（continue）
b main.py:16在第 16 行下断点
b fib在函数入口下断点
b 24, n == 2条件断点：只有 n == 2 才停
cl 1删掉 1 号断点
p CALLS打印变量
pp locals()打印得更整齐
w调用栈（递归时最有用）
u / d在栈里上移／下移一层
q退出

5. 终端启动 + 界面调试（attach）

# 终端 A：程序启动后挂起，等你连上
python -m debugpy --listen 5678 --wait-for-client main.py

# 终端 B（或直接 VS Code）：连上去
# F5 → 选 "Python: 附加到 5678 端口"

用途：程序要带一堆参数、要被别的脚本调用、或者你想在它崩掉的那一刻接上去。--wait-for-client 不能省，否则程序在你连上之前就跑完了。

6. 报错对照

现象原因处理
python 不是内部或外部命令Python 没进 PATH用 py，或重装时勾选 Add to PATH
python3 提示去 Microsoft Store 安装Windows 上的 python3.exe 是商店占位符（0 字节），不是 Python改用 python 或 py；python3 是 Linux/macOS 写法
ModuleNotFoundError包装到了别的解释器看提示符有没有 (.venv)，再 where python
禁止运行脚本 Activate.ps1PowerShell 执行策略Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
pip 不是命令venv 里没 pippython -m ensurepip --upgrade
F5 弹出「选择调试配置」没打开 .py，或没有 launch.json先打开脚本，F5 会提示自动生成
断点是空心灰圈解释器不对／扩展没激活重选解释器，Developer: Reload Window
断点跳过去了没停那一行没被执行到，或 justMyCode 挡了库代码设 justMyCode: false，或把断点挪到确实会走的分支
中文乱码终端代码页chcp 65001，或环境变量 PYTHONUTF8=1
一条铁律

任何「装了包却 import 不到」「pip 成功但代码报错」的问题，先跑 python -c "import sys; print(sys.executable)"。九成情况下它指的不是你以为的那个 Python。
